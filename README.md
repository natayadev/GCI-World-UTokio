# GCI-World-UTokio

Coursework and notes for **GCI World 2026 (April)** at the University of Tokyo — a data science / machine learning program combining lectures, homework, a Kaggle-style competition, and a final group assignment.

## Structure

- **`competition/`** — Kaggle-style competition on NFL draft prediction.
  - `baseline.ipynb` — baseline model.
  - `nfl_draft_prediccion.ipynb` — main competition notebook.
  - `advanced_techniques/` — tutorials on feature engineering, hyperparameter tuning, and model ensembling.
  - `input/` — competition datasets (`train.csv`, `test.csv`, `sample_submission.csv`).
  - `competition_tutorial.pdf` — competition guide.

- **`final assignment/`** — Group final project: customer churn analysis for a telecom company.
  - `final_assignment.ipynb` / `tutorial.ipynb` — analysis notebooks.
  - `telecom/` — datasets (`Client.csv`, `Record.csv`).
  - `README.docx`, `ENG_Company_A_Dataset Overview.docx` — assignment brief and dataset description.
  - `Sample1.pptx`, `Sample2.pptx` — example presentation slides.
  - `final_assignment_telecom.pdf`, `final_assignment_tutorial.pdf` — reference PDFs.

- **`homeworks/`** — Weekly homework notebooks (`HW1`–`HW8`, one per session).
  - `MyAnimeList-Database-master/` — sub-project scraping and building a MyAnimeList database (used in one of the homework exercises).
